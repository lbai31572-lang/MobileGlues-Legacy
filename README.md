MobileGlues-Legacy
It is derived from the open-source renderer MobileGlues. MobileGlues-Legacy aims to be one of the solutions for older versions that lack shader support and have low rendering efficiency.
The porting of this project was completed by DeepSeek and GPT 5.6.
Since this is the initial version, and because MobileGlues itself was created for versions above 1.17, there may be some rendering issues. We will try our best to fix them in subsequent versions.
